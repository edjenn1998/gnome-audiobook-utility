# Audiobook Utility 0.1.1

## Changes

- Protected-media identification survives renamed extensions; conversion and merge
  results are completely decoded before publication.
- Durable non-secret download journals preserve recoverable receipt/license
  associations. Receipt validation, backups and concurrent updates are hardened.
- Disconnect retains conversion licenses. Separate confirmed Forget Licenses
  removes only media licenses and retains authentication.
- Every transfer redirect requires HTTPS; transfers, retries and cover retrieval
  are bounded. Corrupt/expired cover-cache entries recover within a fixed quota.
- Native progress is coalesced, library rows are recycled and previews are prepared
  in workers. Metadata prompts protect unsaved text and artwork changes.
- ADTS-first merging, explicit cover removal, nullable library metadata, literal
  external titles, temporary paths and keyboard cancellation are corrected.
- Packaged source uses an explicit tracked manifest; dependency integrity,
  launcher error handling, CA configuration and optimized validation are hardened.
- Credential-free core/native CI and fresh-state local checks are included.

## Build and validation

The x86_64 AppImage is built on CachyOS using the existing native runtime and locked
Python dependencies. No system package installation or real Audible account
operation is required. Build provenance is embedded at
`/usr/share/audiobook-utility/appimage-build.json` inside the private runtime.

- Local source gate: **192 passed**, 49.20 seconds; Ruff and whitespace passed.
- Isolated PEP 517 wheel and editable builds passed using project-local targets.
- Hosted core and full native lanes passed on Ubuntu 26.04:
  [validated workflow](https://github.com/edjenn1998/gnome-audiobook-utility/actions/runs/41969331345).
  The original Ubuntu 24.04 lane used an FFprobe too old for secure file-valued
  options; the supported CI baseline and display-before-bus startup were corrected.
- Candidate AppImage normal/FUSE and extract-and-run modes passed conversion,
  merging, chapters, metadata, full decode, cover display, GTK/Adwaita, ephemeral
  WebKit callback and public Amazon form/HTTPS checks, without account login.
- Bundled encrypted-tone conversion passed protected-brand detection despite a
  misleading `.m4b` suffix, missing-license rejection, inherited private key-option
  transport, complete PCM equality, two chapters and unchanged source bytes.
- Embedded public-source hashes match all **82 approved source files**. Candidate
  provenance identifies a clean committed source revision and locked dependencies.
- Actual runtime CA mounts passed against a synthetic local HTTPS server through
  HTTPX, libsoup/GnuTLS and WebKit: untrusted by default, trusted with either an
  explicit override or additional CA, malformed CA rejected. TLS and WebKit
  sandboxing remained enabled.

The final asset is rebuilt from the merged release revision and rechecked before
publication. The downloadable `.AppImage.sha256` records its exact digest; the
release validation JSON records the tested image and provenance. The old v0.1.0
image checksum remains `83553972578ed8debf0e445043fb7a1cd44d059f43e87e3850bea56ecb9f0791`.

## Compatibility and acceptance boundary

Requires x86_64 Linux, unprivileged user namespaces, a graphical desktop and normal
D-Bus/Secret Service for account operations. Other distributions and CPU generations
need the matrix in `../portability.md`; no universal portability claim is made.
Interactive MFA/CAPTCHA, screen-reader/scaling checks and detailed listening/player
navigation remain owner acceptance work. The historical v0.1.0 asset is preserved.
